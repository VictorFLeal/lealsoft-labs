# LealSoft Labs

Landing page oficial da LealSoft Labs.

A LealSoft Labs é uma startup focada no desenvolvimento de sistemas SaaS, plataformas inteligentes, automações e soluções modernas para empresas.

---

## 🚀 Sobre o Projeto

Este projeto representa o site institucional da LealSoft Labs, desenvolvido para apresentar:

- Serviços da empresa
- Soluções SaaS
- Identidade visual da marca
- Tecnologias utilizadas
- Portfólio e posicionamento da startup

---

## 💻 Tecnologias Utilizadas

- React
- Vite
- JavaScript
- Tailwind CSS
- Lucide React

## 🎨 Objetivo

A landing page foi criada com foco em:

## 📦 Instalação

Clone o projeto:

```bash
git clone https://github.com/lealsoft-labs/lealsoft-labs.git
```

Entre na pasta:

```bash
cd lealsoft-labs
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

---

## 🛠️ Build de Produção

```bash
npm run build
```
